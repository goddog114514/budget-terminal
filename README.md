# BUDGET::TERM — 个人记账与自动理财规划终端

一个仿 PowerShell 风格的本地记账 Web 应用：黑色背景、等宽字体、绿/白/彩色文字，
用**命令行输入** + **顶部按钮（辅助）**双通道操作，所有数据保存在浏览器 `localStorage`
（无需安装、无需联网、无后端）。

**单文件应用：** 双击 `index.html` 用浏览器打开即可使用。

---

## 快速上手

打开后即可直接在底部命令行输入，例如：

```text
set budget 1000        # 设置本周期(默认自然月)固定预算 1000 元
add 50 餐饮 午餐        # 记一笔 50 元餐饮消费，备注“午餐”
add 300 购物 外套       # 再记一笔
list                    # 查看所有消费记录
budget                  # 看预算进度条与剩余额度
pay 1 all               # 把第 1 笔对应的投资标记为“已投资”
summary                 # 本周期自动总结
summary week            # 本周总结
export md               # 下载 Markdown 报告
```

每笔消费会自动换算"占用预算"与应投金额并关联显示：

- **占用预算 = 消费 ÷ 0.85**（消费只占预算的 85%）
- 占用预算的 **15%** 用于投资：**13%** → 货币基金、**2%** → 指数基金
- 例：消费 `¥850` → 占用 `¥1000`，应投 货币 `¥130` + 指数 `¥20`
- **剩余自动结转下一周期**；**透支自下一周期扣除**（见下"预算模型"）

例如 `add 50 餐饮 午餐` 会算出：占用预算 `¥58.82`，应投货币 `¥7.65` + 应投指数 `¥1.18`。

### 投资池与一键投资
- 每条记录拆为两栏 **应投货币** 与 **应投指数**，各自把"未投部分"跨期累加成池。
- 界面顶部「理财条」实时显示两池：**应投货币池 / 应投指数池**（未投累计）＋各自累计已投。
- 当**应投货币池累计 ≥ ¥100**、**应投指数池累计 ≥ ¥20** 时，该池金额**变绿**，旁边的 **`全额投资`** 按钮点亮（在此之前显示“待满 ¥100/¥20”并禁用）。
- 点 **`全额投资`**：把该种整个未投池一次性投入并清零，金额**按各笔未投金额比例自动分摊**（支持一笔只投一部分），记入累计已投，池归零重新累计下一批。
- 例：消费合计 ¥850 → 应投货币池 ¥130、应投指数池 ¥20，两个全额投资按钮同时点亮；点货币“全额投资”即投入整池 ¥130（清池），指数同理投 ¥20。
- `list` 每行右侧按钮可一键把该行应投货币+指数全部标记已投（再点重置），行内状态即时更新。

## 命令参考

| 命令 | 说明 |
| --- | --- |
| `help` | 查看帮助 |
| `set budget <金额>` | 设置每周期固定预算，如 `set budget 1000` |
| `set period <N天>` | **滚动 N 天周期**：如 `set period 15` 每 15 天滚动一期（从当日起算）；`set period natural` 回到按月周期 |
| `set periodstart <YYYY-MM-DD>` | 设定滚动周期起点/锚点日期（之后每 N 天滚动） |
| `set monthstart <1-28>` | 按月周期时的起始日：`1`=自然月，`15`=每月 15 日~下月 14 日为一周期 |
| `set weekstart <mon\|sun>` | 周总结起始日：周一或周日 |
| `set alert <p1,p2,…>` | 自定义预警阈值（百分比），默认 `80,100` |
| `set rate <money\|index> <%>` | 设置基金年化收益率（用于资产模拟），如 `set rate index 8` |
| `assets [N年]` | **资产看板**：现金+货币/指数本金、按年化复利的 N 年后预估、总资产、ASCII 增长曲线（默认 10 年） |
| `undo` / `redo` | 撤销 / 重做上一次数据改动（也可 Ctrl+Z / Ctrl+Y，或工具栏按钮） |
| `budget` | 当前周期预算进度（进度条+超额状态+一行燃尽预测） |
| `budget set <金额>` | **只调整当前周期**的预算，如 `budget set 1200`（以后各期不变） |
| `budget default <金额>` | 调整默认预算（以后各期）；`budget reset` 取消当期覆盖 |
| `forecast` | **燃尽预测**：按日均消费预测期末结余/超支与剩余每天可花 |
| `add <金额> <类别> [备注..] [@日期]` | 记一笔消费；`@YYYY-MM-DD` 指定非今天日期 |
| `list [类别] [@月份]` | 列出消费记录；每行右侧有 **`[标记已投资]`** 按钮，点一下即已投、再点取消（也等同 `pay <id> all/none`） |
| `del <id>` | 删除记录 |
| `update <id> <金额> <类别> [备注..] [@日期]` | 修改记录并自动重算投资额 |
| `pay <id> [mm\|idx\|all\|none]` | 命令方式标记投资已投：`mm`货币基金 / `idx`指数基金 / `all`全投 / `none`未投 |
| `summary [day\|week\|month] [类别]` | 总结窗口：无参数 = **当前记账周期**；`month` = **自然月（当月 1 日～月末）**；`day` = 今日；`week` = 本周。可选在末尾**按类别筛选**，如 `summary week 餐饮` |
| `summary month [@YYYY-MM] [类别]` | 自然月总结，可指定月份 + 类别，如 `summary month 2026-08 餐饮` |
| `summary cat [类别]` | 当前记账周期各类别占比明细 |
| `summary 类别` | 省略窗口关键字时，默认用当前记账周期 + 该类别，如 `summary 医疗` |
| `export [md\|txt]` | 导出报告（浏览器下载） |
| `config` | 查看当前配置 |
| `cls` | 清屏 |

> 备注含空格时可加引号，如 `add 50 餐饮 "和同事 午餐 AA"`。
> 上下方向键可翻历史命令；点击终端任意位置即可继续输入。
> **撤销/重做**：`undo` / `redo`（Ctrl+Z / Ctrl+Y）可回退误删误改；工具栏也有 ↩/↪ 按钮。
> **资产看板**：`assets` 用 `现金余额 + 已投基金本金` 合成总资产，并按设定年化做复利推演与 ASCII 曲线。
> **燃尽预测**：`forecast` 按日均消费预测期末结余/超支与「剩余每天可花多少」，`budget` 末尾也有一行简报。
> **当期预算**：`budget set 1200` 只改本期；`budget default 1200` 改默认（各期）；`budget reset` 取消本期覆盖；工具栏「配置预算」按钮可弹窗操作。
> **Tab 补全**：输入时按 Tab 自动补全命令，再按 Tab 在候选中循环（会显示候选清单）。
> **淡色"将输入"提示**：当只剩唯一候选时，光标后会用淡色预览待补字符，按 **→(右方向键)** 直接接受；多候选时按 Tab 逐个循环。
> 支持两级：命令名 + 参数（类别、`mm/idx/all/none`、`set` 子命令、`day/week/month`、`md/txt`、记录 id 等）。

## 总结（summary）用法

### 1. 按类别筛选
在任意总结命令**末尾加上类别名**，即只统计该类别的消费；不加则统计全部：

```text
summary day            # 今日全部
summary day 餐饮        # 今日只看餐饮
summary week 医疗       # 本周只看医疗
summary month 餐饮      # 本自然月只看餐饮
summary month 2026-08 餐饮   # 指定月份 + 类别
summary 医疗            # 省略窗口关键字 → 当前记账周期 + 医疗
summary cat 交通        # 当前周期各类别占比(限定交通)
```

- 类别名会显示在标题里，如 `═ 今日 2026-09-18  [类别: 餐饮] 总结 ═`。
- 窗口内没有该类别时会给出提示，并列出**现有类别**（含自定义类别）。
- 类别支持 Tab 补全（已知类别 + 历史记录里出现过的所有类别）。

### 2. 平均每日消费
除 `summary day` 外，每次总结末尾都会多出一段：

```text
 ── 平均每日消费 ──
 日均 ¥16.67   = 窗口总消费 ¥300.00 ÷ 18 天
 统计口径: 窗口 30 天, 已过 18 天
```

- 计算方式：**窗口总消费 ÷ 统计天数**（已按类别筛选时，就是该类别的日均）。
- **进行中的窗口**只按“已过天数”平均（如本月 18 号看月总结 → ÷18 天），避免被未到的日期稀释；
  **已结束的窗口**（如 `summary month 2026-08`）按整个窗口天数平均。
- `summary day` 不计算（单日总量即日均，无意义）。
- 预算行（本期发放 / 占用 / 结转 / 累计余额）仍是**当前记账周期**口径，不随窗口或类别变化。

## 两种记账周期

1. **固定天数滚动周期**（适合“每两周/每 15 天”结算预算）
   ```text
   set period 15            # 从现在起，每 15 天滚动一期
   set periodstart 2026-09-04   # (可选)指定从哪天起算，之后每 15 天滚动
   ```
   预算、进度、超额预警、`summary` 均按当期 15 天窗口计算；超过第 15 天自动进入下一期。

2. **按月周期**（自然月或自定义起始日）
   ```text
   set period natural       # 回到自然月
   set monthstart 15        # 每月 15 日 ~ 下月 14 日为一期（想错位对齐时推荐）
   ```

## 预算模型（85% 消费 / 15% 投资 + 结转）

设某期发放总预算 **B = 1000**（默认，可用 `set budget` 改）：

- 消费只占预算的 85%；每笔消费 `E` 记为本期**占用** `E ÷ 0.85`。
  例如消费 850 → 占用 1000；消费 425 → 占用 500。
- 占用的 15% 作为自动理财：**13% → 货币基金、2% → 指数基金**。
  例如消费 850 → 应投货币 130 + 指数 20（合计 150）。
- **结转/透支（跨期累计）**：
  - 本期占用 < 发放 → 差额为"剩余"，**自动结转到下期**（可用余额增加）。
  - 本期占用 > 发放 → 差额为"透支"，**自下一期发放中扣除**。
  - 例：消费 425、占用 500 → 本期可结转 500，可用余额 500；下期发放时余额 += 1000。
  - 例：消费 900、占用 1058.82 → 透支 58.82，可用余额为 -58.82，下期 +1000 后先扣回。

顶部状态栏、`budget`、`summary`、`export` 均按此口径显示「本期消费 / 应投 /
已占用 / 可结转·透支 / 累计可用余额」，并据占用率触发预警（默认 80%/100%）。

> **总结窗口 vs 预算口径**：`summary` 的**消费窗口**可选 —— 无参数 = 当前记账周期；
> `summary month` = **自然月（1 日~月末）**，与记账周期解耦（即使周期设成 15 天滚动，
> 也能看日历月账单）；`summary day/week` 对应今日/本周。
> 但表中的**预算行**（本期发放 / 本期占用 / 结余·透支 / 累计余额）始终按**当前记账周期**计算，
> 因为预算本来就是按周期发放与结转的。

## 本地备份与防丢失

数据默认存在浏览器 `localStorage`，刷新/换浏览器/清理缓存会丢失。三种本地保存方式（工具栏按钮）：

1. **存到本地目录（推荐，防自动丢失）** — 只需选一次文件夹：
   - 程序把全部记录/设置写入该目录的 `budget_term_backup.json`，之后**每次改动都自动写盘**；
   - 所选目录会记在 IndexedDB，**以后每次点开应用**：若浏览器仍授权，打开即自动重连并继续自动写盘；若新会话授权过期，在你第一次点击/按键时**自动**重新申请授权（无需再专门点按钮）；
   - 需要 **Chrome / Edge / Opera**（File System Access API，建议用 `http(s)` 或本地服务器方式打开，持久授权更稳定）。
2. **备份 .json** — 任何浏览器可用：下载一份完整快照文件，可存到本地归档。
3. **导入 .json…** — 选之前备份的文件即可整体恢复记录与设置（会替换当前数据）。

提示：以上文件都是**纯文本 JSON**，可放心存到云盘/网盘；即使浏览器数据全清，导入一次即可找回所有记录。

## 说明 / 提示

- 未开启“存到本地目录”时，数据只存当前浏览器；请勿用隐私/无痕模式，或用「存到本地目录 / 备份 .json」留存。
- 修改 `预算金额` 会影响"发放进度"与结转；已录消费不受影响（但其应投金额始终按新口径换算）。
- 导出报告（`export md/txt`）为另存的报告文件，与上述 JSON 备份不同。
