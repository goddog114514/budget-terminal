## 一句话

以前所有花费都算在"记的那一天"：一笔年付房租 `¥3600` 会把当天账单直接打爆。
现在 `amort 3600 365 房租 年付` 会把它摊成**每天 `¥9.86`**，而**投资仍按总价 `¥3600` 一次记入**
（货币 `¥550.59` + 指数 `¥84.71`）—— 每天都能看到真实成本，投资池也不会因为分摊而少算。

## 一、新功能：分摊成本 `amort`

```text
amort 3000 365 房租 年付房租     # 总价 3000 元，摊到 365 天 → 每天 ≈¥8.22
amort 600 12月 会员 年费         # 天数可写 12月 / 12m / 12个月（按 30 天/月 = 360 天）
amort 1200 90 保险 @2027-08-01   # 指定开始日期（@ 位置随意）
```

| 参数 | 说明 |
| --- | --- |
| `<总价>` | 一次性付出的总金额（> 0） |
| `<天数>` | **2 ~ 3650**；可写 `12月` / `12m` / `12个月`（×30 天） |
| `<类别>` | 与 `add` 同一套类别体系（自定义类别、Tab 补全、配色都照旧） |
| `[备注..]` | 可选，含空格加引号 |
| `[@开始日期]` | 可选，默认今天；`@` 参数不占位置 |

### 两个口径（核心设计）

设总价 **T**、分摊天数 **N天**、消费占比 **N%**（默认 85%）：

| 口径 | 算法 | 效果 |
| --- | --- | --- |
| **消费（计入每天）** | `每天 = T ÷ N天` | 周期占用、`budget`、`summary`、燃尽预测、日均全部按天自动生效 |
| **投资（只记一次）** | `应投 = T ÷ 消费占比`，再按 **13:2** 拆池 | **不分摊**：整笔总价的应投额一次性进投资池 |

> **为什么"投资只记总数"不会少算？** 因为
> `Σ(每天 ÷ 消费占比) = 总价 ÷ 消费占比` —— 按天摊与按总额算得到的**投资总数完全相等**，
> 区别只是投资记的是**一次的总数**、不跟着每天重复计息。护栏里有专门断言这一恒等式。

## 二、「记一笔」弹窗改成两个选项卡

点工具栏 **`+ 记一笔`**，弹窗顶部多了两个选项卡：

| 选项卡 | 用途 | 字段 |
| --- | --- | --- |
| **单笔消费**（默认，与以前完全一样） | 一笔消费 | 金额 / 类别 / 日期 / 备注 |
| **分摊成本** | 总价摊到每天 | **总价** / **分摊天数** / 类别 / 起始日期 / 备注 |

- **实时预览**：`= 每天 ¥10.00 × 360 天（合计 ¥3600.00），从 2027-08-01 起`
  `应投按总价一次记入: 货币 ¥550.59 + 指数 ¥84.71`
- **非法输入拦住并说明原因**（黄色）：天数不在 2~3650、每天不足 `¥0.01`、天数不是数字。
- 起始日期用**月份**输入（分摊本身就是跨月行为），提交时拼成 `@YYYY-MM-01`。
- 弹窗与命令行走**同一条 `amort` 命令**（拼串回灌 `runCommand`），所以两条通道行为、撤销栈、日志格式完全一致。

## 四、兼容性（老数据必须永远能导入）

`normalizeRecords()` 的改动是**纯加法**，并且对坏数据也是安全的：

| 情况 | 处理 |
| --- | --- |
| 老记录（没有 `amortDays` / `amortTotal`） | 视为普通消费（1 天），`amount` 就是总额 —— **行为与 v0.0.5 完全一致** |
| `amortDays` 非法（缺失 / ≤1 / 超上限 / 非整数） | 回落为普通消费（1 天） |
| `amortTotal` 缺失但天数有效 | 按 `每天 × 天数` 补回，应投按补回的总价算 |
| 备份往返 | `amortDays` / `amortTotal` 原样保留，应投不变 |

**未改动**：`LS_KEY`、备份 `app` / `version` 头、13:2 拆池、`r2` / `r6` 精度、`INV_EPS` / `INV_UNIT`、响应式契约。
实测：同一份旧备份（153 条记录）在 v0.0.5 与 v0.0.6 下归一化结果**逐字段字节一致**。

## 六、这一版没做什么

- **`update` 的可视化编辑**：`update` 已正确支持分摊记录（金额按每天解释），但弹窗的 edit 分支仍是**既有的不可达死代码**
  （见 `ARCHITECTURE-REVIEW.md` H5），本次没有顺带做"列表行 ✎ 编辑"入口。
- **改分摊天数**：`update` 只改每天金额与总价，想改天数请 `del` 后重新 `amort`（天数目前不在 `update` 的参数里）。
- **H4（统一 commit 出口）**：仍是下一版的首选项，本次未动。
