# BUDGET::TERM v0.0.14 发布说明

> 不转账、不改可用余额、不改"占用 = 消费 ÷ N"的记账口径；老数据与老备份零迁移。

- **版本号**：`config` 输出与开机 banner 显示 `v0.0.14`
- **回归**：`node tests/run-all.mjs` = **1212 条全绿**（152 / **59** / 123 / 123 / 92 / 59 / **241** / 163 / 73 / **127**）；

## 一、做了什么

| 能力 | 说明 |
| --- | --- |
| 总可用余额 | **当期预算 × 可消费比例**（`config set invest` 可调，默认 85%）；预算 1000 → ¥850.00 |
| 已配置 / 可配置 | 已配置 = 各类别金额之和；可配置 = 总可用余额 − 已配置。配置页与弹窗都实时显示 |
| 命令 | `set category`（查看）、`set category 餐饮 400 交通 300`（多类别）、`set category 餐饮 off`、`set category reset` |
| 表格 | 类别 / 已分配 / 已支出 / 剩余可用 / 使用率 + 合计；已支出按**本期**统计（分摊按落在本期的天数计入） |
| 配置页 | `config` 多出三行：总可用余额（带 `预算 × N%` 口径）、已配置/可配置、明细（每类 已分配 + 实时使用率） |
| 界面 | 「配置 ▾ → 配置类别余额」：每行 `色块 + 类别 + 数字输入 + 浅色实时可配置余额 + 实时占比` |
| 预警圆点 | 类别达到阈值时，在顶栏「今日预算 / 周期预算」**之前**插入同款实心圆点 + 比例（`餐饮：●113%`）；**未超标完全不显示**，多项横向排开 |
| 静默开关 | 类别名后的勾选框（默认勾选）= 该类别是否提示超额；`set category 餐饮 400 nowarn` 同款。取消后该类别**完全不产生警告**（顶栏/`budget` 都不出现，明细标「静默」）；金额、排序、占比与合计不变 |
| 工具栏收敛 | 去掉「预算进度」按钮：周期预算在打开页面时（首屏）已自动输出，之后只看 `budget` 命令；顺带删掉不可达的 `open-budget`/`open-invest` 分支 |

## 二、使用示例

```text
set category 餐饮 400 交通 300     # 一次配两个类别（合计 700 ≤ 850）
set category 餐饮 400 nowarn       # 该类别不提示超额（nowarn | silent | 静默）
set category                       # 查看总可用 / 已配置 / 可配置 + 每类使用率
set category 购物 off              # 取消该类别（写 0 也一样；静默标记一并清掉）
set category reset                 # 全部清除（含静默标记）
```

预算 1000、配置餐饮 400 / 交通 300、本期餐饮已花 350 时：

```text
  ▓ 类别余额  2027-08-01 ~ 2027-08-31
  总可用余额      ¥850.00   (当期预算 ¥1000.00 × 消费 85%)
  已配置          ¥700.00   (2 个类别)
  可配置余额      ¥150.00
  类别   已分配    已支出    剩余可用   使用率
  餐饮   ¥400.00  ¥350.00  ¥50.00     87.5%
  交通   ¥300.00  ¥0.00    ¥300.00    0.0%
  合计   ¥700.00  ¥350.00  ¥350.00
```

顶栏（餐饮 87.5% = 黄灯，在「今日/周期预算」之前）：

```text
餐饮：●87%    今日预算：●剩余55%    周期预算：●已超额114%
```

## 三、规则与边界

- **已配置合计 ≤ 总可用余额**：超出时命令直接拒绝，弹窗变红并拦住保存。
- **已经超额只能减不能加**：例如后来把预算调低导致总可用余额变小，仍可继续下调类别，但不能新增/加高。
- **类别余额不是转账**：不动现金、不动可用余额与结转，只决定每个类别的天花板；改预算会立即改变总可用余额。
- **阈值共用**：类别圆点与「今日/周期预算」用同一份 `set alert`（默认 80,100）——最低阈值转黄、最高阈值转红。
- **未超标不渲染**：顶栏与 `budget` 的圆点区不会留空位、不会显示 0%。
- **静默只关警告**：`nowarn`（或弹窗里取消勾选）让该类别不产生任何超额警告，但金额、排序、占比、
  总可用余额与已配置合计一概不变；`off`/`reset` 会同步清掉静默标记，归一化也只保留"仍配置了额度"的静默项。
- **保存是一步撤销**：弹窗把整张表拼成**一条** `set category …`（清零的类别显式发 `off`、取消勾选的带 `nowarn`），与命令行同一条通道。
- **预算块只出现在两处**：打开页面时的首屏（`boot()` → `showBudget()`）与 `budget` 命令；工具栏不再有重复入口。

## 四、架构与数据

- 新增 `settings.categoryBudget = {类别: 已分配金额}` 与 `settings.categoryMute = {类别:true}`，随 `settings` 一起进备份/导入/撤销栈；
  `normalizeSettings()` 丢弃 0/负数/非数字/空键/`r2` 后为 0 的项，类别名截断到 `CAT_NAME_MAX = 60`；
  静默项只保留"仍配置了额度且值为 true"的类别（取消分配不会留下静默标记）。
- **口径单一来源**：`catPool()` / `catAllocated()` / `catPoolLeft()` / `catBudgetRows()` / `catAlertList()`；
  顶栏、`budget`、`config`、命令表格、弹窗全部复用，不在任何地方重写"求和/取已用"。
- 已支出走 `collectWindow(p.start, p.end, 类别)`，与 `summary`/`budget` 同一套窗口与分摊口径。
- `set category` 以**子用法**登记在 `COMMANDS`（`sub:true`），不新增主名/别名；
  help、Tab 补全（类别槽 → 已知类别 + `reset`，金额槽 → `off` + 常见额度）都从登记表派生。
- 弹窗顶部 summary 与行内文字全部 `textContent` 渲染（类别名是用户输入）；`innerHTML` 仍只用于清空。
