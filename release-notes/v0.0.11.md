## 一、四类可复用的图形块

全部是 **DOM 元素**（不是图片、不写 `innerHTML`），数字仍在可复制的文本里；
配色与图表共用同一套语义：绿=正常/结余、黄=预警、橙/红=越线或超支、青=货币、浅黄=指数。

| 组件 | 作用 | 出现在 |
| --- | --- | --- |
| `sectionHead(title, meta, color?)` | 章节标题：`▓` + 大一档青色标题 + 灰色副标题（`chartHead()` 现为它的别名） | 全部命令 |
| `ratioBar(ratio, {label, sub, color})` | 横向比例条：圆角轨道 + 同色填充 + **100% 虚线刻度**（超额时刻度落到内部 `1/r` 处） | `budget` / `forecast` / `summary` |
| `stackBar(parts[], {title})` | 堆叠条 + 色块图例 | `assets`（资产构成）/ `forecast`（额度拆分） |
| `catRows(cats, total)` | 类别行四列：类别 / 细条 / 占比 / 金额（条长按占最大类别的比例） | `summary` |
| `miniBars(points[], opts)` | 迷你柱状图，复用 `.chart-bars` 的柱样式 | `assets`（增长曲线） |

> 原先的 `████░░░░` 字符条与 `▁▂▃▄▅▆▇█` 字符曲线**全部退役**：字符宽度随字体漂移、亮度不可控，
> 与柱状图不是同一套颜色语义。`sparkline()` 已直接删除，不留死代码。

## 二、逐命令的变化

### `budget`
- 标题：`▍周期预算 ( 周期 )` → **`▓ 周期预算   <周期>`**。
- 明细：三段挤在两行的写法 → **列对齐 KV 表**，并补上算式与拆分：
  `本期发放` / `本期消费（含笔数）` / `应投合计（货币 + 指数）` / `已占用(含应投)` /
  `累计可用余额(含结转)` / `本期结余/透支（发放 − 占用）`。
- 新增 `<本期发放进度>` 比例条（含 100% 额度虚线），下面的透支/结转提示、红黄绿圆点、
  换算口径、燃尽预测一行**全部保留**。

### `forecast`
- 标题：**`▓ 燃尽预测   <周期>  (已过/总天数)`**。
- 表格不变（列宽仍与 `summary` / `assets` / `config` 完全一致，`test3` U1–U3 守着）。
- 新增**消费额度堆叠条**（已消费 / 剩余可用）与**期末预测占用比例条**（虚线 = 100% 发放线），
  原来那根字符进度条退役。

### `assets`
- 标题：**`▓ 资产看板   年化 货币 x% / 指数 y%`**。
- `预估增值` 补上百分比；新增**资产构成堆叠条**（现金 / 货币 / 指数，本金的占比一目了然）。
- 增长曲线：`▁▂▃▄▅▆▇█` → **真柱状图**（最多 6 根，含"现值 → 第 N 年"金额与累计涨幅，
  超过 6 年自动按 `ceil(N/5)` 采样，避免数值标签互相压住）。

### `config` / `list` / `summary` / `chart` / `report`
- 标题统一走 `sectionHead()`（图表章节的 `▓ 柱状图 / ▓ 饼图 / ▓ 数据明细 / ▓ 自动分析 / ▓ 总结与建议` 同步受益）。
- `summary`：`本期发放进度` 改比例条，类别占比由字符条改 `catRows()`（`report` 里仍然只在饼图出现一次，去重不变）。
- `report` / `chart` 的标题前缀 `═ … ═` 改为 `▓ …`，**输出顺序与去重逻辑完全未变**。

## 六、同版迭代：进度条改「方形 + 分色」

> 仍是 `v0.0.11`（同日追加，未升版本号、未打标签）。

- **形状**：`.hbar` / `.hbar-fill` / `.hbar-rest` / `.stack` / `.cat-track` 一律 `border-radius:0` —— 直角方块，
  轨道高 12px（顶部栏迷你条 9px）。

## 七、同版修复：饼图切片严格闭合

> 仍是 `v0.0.11`（同日追加，未升版本号、未打标签）。

- **现象**：饼图看上去"没闭合"——某个位置像被挖掉一块（相邻两片同色时尤其明显，如 `话费` / `会员`）。
- **根因**：上一轮为了做出"分隔线"，在 `conic-gradient` 的每片结束处插入了 `transparent` 停靠点：
  `col from% (to-0.5)%` + `transparent (to-0.5)% to%`。这等于在饼图上**真的挖掉一个 1.8°（0.5%×360°）的缺口**，
  不是视觉缝线；切片越窄、或两侧同色，缺口就越像"少了一块"。
- **修法**：切片一律 `from → to` 首尾相接，**禁止 `transparent` 停靠点**；最后一片仍强制收敛到 `100%`。
  示例数据（6 片）实测整圈覆盖 **100.00%**、洞 **0** 个。分隔交给相邻色差。
- **护栏**：`test7.mjs` 新增 **CH4.19**「饼图严格闭合（无透明缺口、0%→100% 连续）」，196 → 197 条；
  变异脚本新增 `m_chart_pie_gap`（把透明缺口改回去 → 立即变红），共 **33 组**全部被抓住；全量 **718 条**全绿。

## 八、同版迭代：柱状图随分辨率自适应

> 仍是 `v0.0.11`（同日追加，未升版本号、未打标签）。

- **现象**：2K/4K 屏或把窗口拉宽后，资产看板的堆叠条只占中间一小段（`.stack-wrap` 上限 `640px`），
  柱状图同理——列宽被 `min-width:28px` 顶住、柱宽写死 `22px`，右侧留一大片空白；竖屏/窄窗口又容易挤。
- **修法（宽度）**：`.stack-wrap` 去掉 `max-width` 上限；`.chart-bars` `width:100%` + `flex:1 1 420px`；
  `.chart-col` 改 `flex:1 1 0` 均分可见宽度；`.chart-bar` 宽度 `clamp(10px,58%,34px)`；间距 `clamp(4px,0.9vw,18px)`。
- **修法（高度）**：绘图区高度不再写死 218/150px，改由 JS 写入 `--plot-h`（`plotHeight()` 按 `innerHeight`
  在 **0.8x~1.35x** 缩放，1080p ≈ 0.95x）；CSS 用 `height:calc(var(--plot-h) + 24px)` 加标签留白，
  两者共用同一个数字，不会出现"柱高 192px、容器只有 150px"的错位。
- **重排**：新增 `applyPlotHeight()`，柱高 / 柱顶数值 / 预算参考线 / 零轴统一在这里落位；
  `resize` 时对所有 `.chart-bars` 重跑一次（只改内联样式，不重算数据）。
- **护栏**：`test3.mjs` §7 新增 5 条（宽度 100% / 列 flex 均分 / 柱宽 clamp / `--plot-h` 驱动高度 / 堆叠条无 640px 上限），
  103 → **114** 条（本段 5 条 + §九 6 条）。

## 九、同版修复：数值为负时图形不显示

> 仍是 `v0.0.11`（同日追加，未升版本号、未打标签）。

- **现象**：现金为负（透支/超支结转）时，资产看板的「资产构成」堆叠条里**看不到负的那一段**；
  增长曲线在总资产为负时所有柱被压成 2px，等于"图形不显示"。
- **根因 ①**：`stackBar()` 用 `filter(p=>p.value>0)` 把负值整段丢掉。
- **根因 ②**：柱高按 `H*value/max` 计算，负值得到负高度 → 被 `Math.max(2, …)` 夹成 2px；
  且 `maxVal = Math.max(1, …)` 在全负数据下把分母锁死为 1。
- **修法**：
  - `stackBar()` 保留负值（只滤 `!==0`）；含负值时改**零轴排版**（`.stack.mixed` + `.stack-zero`）：
    负段从 0 向左、正段向右，中间画 0 刻度线；百分比分母改用**毛额**（正 + |负|），不再出现负分母。
  - `applyPlotHeight()` 用 `[min, max]` 值域排版：`px = H/(hi-lo)`，负柱 `bottom = zero - h` 从零轴**向下**长，
    标签挂在柱底下方；`lo<0` 时自动插入 `.chart-zero` 零刻度线。
  - `miniBars()` 传真实 `dataset.max/min`；负值柱默认红色（与全站语义一致）；资产看板里现金为负时，堆叠条那一段也用红色。
- **护栏**：`test3.mjs` 新增 6 条（V8b 全负柱高不再 2px、V8c 负柱向下、V8d 零轴出现、
  V6b/c/d 堆叠条负段保留并按零轴定位）。

## 十、同版重构：预算 / 投资比例统一收进 `config`

> 仍是 `v0.0.11`（同日追加，未升版本号、未打标签）。

- **命令**（设置成功后**直接输出 config 原有的配置表**，不再另写一套确认文案）：

  | 命令 | 作用 |
  | --- | --- |
  | `config` | 查看当前配置（原样输出） |
  | `config set budget <金额>` | 设置默认周期预算（各期生效） |
  | `config set budget <金额> now` | 只改当前周期（默认不变），等价弹窗「应用于当期」 |
  | `config set invest <比例%>` | 投资比例（消费占比 = 1 − 比例），范围 0~50%；`config set consume <占比%>` 也支持 |

- **UI**：工具栏原来的「配置预算」按钮换成 **「配置 ▾」下拉**，两个子项：
  **配置预算**（原预算弹窗）、**配置投资比例**（新弹窗：输入即预览消费/投资占比与换算、越界提示、保存后重算历史应投）。
  两个弹窗提交时都回灌 `config` 命令（`config set budget …` / `config set invest …`），保证"鼠标 = 命令行"同一条通道。
  右下角原「配置」按钮改名为 **「当前配置」**，与下拉区分。
- **兼容**：旧写法 `set budget` / `set invest` / `set consume` / `set ratio` 仍可用（不写进 help，不改变行为）；
  `budget set` / `budget default` / `budget reset` 也保留。`help` 只推荐 `config` 写法。
- **护栏**：`test4.mjs` 新增 11 条（M1.42–M1.52：默认/当期预算、投资比例、越界拒绝、缺参数提示、旧写法兼容、help 不再推荐旧写法）；
  `test6.mjs` 新增 16 条（H5.44–H5.59：下拉容器与两个子项、投资弹窗存在/预填/实时预览/保存/越界拒绝、预算弹窗回灌 config）。
- **文档**：`README` 命令表与示例、`ARCHITECTURE-REVIEW §1.4` 命令表同步（旧写法标为"仅兼容"）。
