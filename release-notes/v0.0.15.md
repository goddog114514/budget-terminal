## 一、周期设置

| 能力 | 说明 |
| --- | --- |
| 命令搬家 | `set period` → `config set period`；`set periodstart` → `config set periodstart`（旧写法仍兼容，help 只推荐 `config`） |
| 截止日 | 新增 `config set periodend <日期>`：设**当前周期**的截止日，天数按"本期起点 → 截止日"自动回算 |
| 起止日直设 | 新增 `config set period <起> <止>`：天数 = 止 − 起 + 1 自动算出；区间必须包含今天，一期 2~366 天 |
| 天数同步 | `lengthDays` 不再手填：一律由日期推导（`periodstart` 只移动锚点、天数不变 → 截止日顺延） |
| 配置页 | `config` 多出「当前周期」行（区间 + 共 N 天 + 改截止日的命令），「周期模式」行末尾指向弹窗 |
| 界面 | 「配置 ▾ → 配置周期」：按月 / 自定义日期分段 + 起止日 + 实时「本期 X ~ Y · 共 N 天 · 下一期 Z 起」；按月模式起止日只读；保存回灌一条命令、一步撤销；校验失败不关窗、不落库 |

```text
config set period 15                     # 滚动 15 天一期
config set period natural                # 回到按月
config set period 2027-08-16 2027-09-30  # 直接指定本期起止日（45 天）
config set periodend 2027-09-30          # 只改截止日（天数自动回算）
```

## 二、经常性支出 recur

| 能力 | 说明 |
| --- | --- |
| 命令 | `recur <金额> <类别> <持续> <频率> [@起始日] [分摊] [备注..]`，别名 `repeat` |
| 持续 / 频率 | 都支持 `日` `周` `周期` `月`：日=1 天、周=7 天、月=日历月（月末夹取不漂移）、周期=记账周期（沿真实周期边界推进） |
| 不分摊（默认） | 生成 **N 笔独立记录**，日期 = 各扣款日；列表/搜索/总结/图表/每日预算/投资池/导出**零特判** |
| 自动分摊 | 只记 **1 笔分摊成本**：总价 = 每次金额 × 次数，摊到整个持续期，投资按总价记一次 |
| 边界 | 一次最多 500 笔、持续期 ≤ 3650 天；持续只有 1 天时无法分摊 → 自动按单笔落账并提示 |
| 界面 | 「+ 记一笔」第三个选项卡「经常性支出」：每次金额 / 类别 / 起始日期 / 持续 + 单位 / 频率 / **自动分摊到每天** / 备注；输入即预览「共几笔 / 总价 / 期间 / 每天金额 / 扣款日」 |
| 编辑 | 生成后每笔都是独立账目，可单独 `update` / `del` / 标记已投资；一次录入 = 一步撤销 |

```text
recur 100 房租 12月 月 @2027-09-01        # 每月 100，持续 12 个月 → 12 笔
recur 100 房租 12月 月 @2027-09-01 分摊   # 同上，但只记 1 笔分摊成本（总价 1200 摊到 366 天）
recur 20 交通 4周 周 @2027-08-02          # 每周 20，持续 4 周 → 4 笔
recur 50 话费 3周期 周期 @2027-08-10       # 每个记账周期 50，持续 3 期
```

## 三、口径说明（为什么这么做）

- 领域不变量规定 `amount` 是"该记的那一天/那一笔的消费额"。让一条记录代表多天多笔会击穿所有窗口统计的唯一入口
  （`recAmountInRange` 等），所以**不分摊时生成 N 笔真实记录**，把复杂度关在录入层。
- 分摊模式复用既有 `amort` 语义：`amortTotal` = 总价、`amortDays` = 持续天数、`amount` = 每天金额，投资只按总价记一次。
- 月频扣款日**从起始日直算**（第 k 个 = 起始日 + k 月，月末夹取）：1/31 → 2/28 → 3/31 → 4/30，不会累积漂移成 3/28。
- 改周期规则**不会**回头重算已经生成的记录（它们是独立账目）；要改请删除后重新录入。

## 四、已知取舍

- 分摊记录的每天金额是 `r2(总价 ÷ 天数)`，逐日累计可能有几毛钱舍入差（与 `amort` 同一既有口径）。
- 「周期」单位依赖**当前**周期规则计算扣款日；之后改 `config set period` 不影响已生成记录。
- 500 笔上限用于挡住"每日 × 多年"这类误输入；需要更长跨度请用「分摊」只记一笔。
