# BUDGET::TERM v0.0.5 发布说明

> 单文件本地记账终端（双击 `index.html` 即用）· 本轮是**重构为主**的版本：
> 把「颜色」「表格渲染」「命令清单」「Tab 补全」四处横向重复的写法收敛成**单一数据源**，
> 删掉一批死函数与死 CSS，并把 **353 条无头回归断言**正式移入仓库。
> **记账语义、数据结构、备份格式、`localStorage` 键全部不变**，旧数据直接可用、无需迁移。

- **发布日期**：2026-10-08
- **提交范围**：[`v0.0.4...v0.0.5`](https://github.com/goddog114514/budget-terminal/compare/v0.0.4...v0.0.5) — 3 commits · 19 files · +4304 / −406
- **升级方式**：用新的 [`index.html`](https://github.com/goddog114514/budget-terminal/blob/v0.0.5/index.html) 覆盖旧文件即可；
  `localStorage` 里的数据与旧 `.json` 备份**完全兼容**（v0.0.1 起的备份都能正确导入）
- **版本号**：标题栏与 `config` 输出显示 `v0.0.5`

## 一句话

肉眼可见的变化只有两处：**四类输出（summary / forecast / assets / config）的数值列现在完全对齐、
且列宽随窗口自适应**，以及下面几个交互缺陷的修复。账本数字本身不会因为升级而变化。

---

## 一、用户可见的修复

### 1. `config` 以前"能用但查不到"

- **现象**：`config`（及别名 `settings` / `thresholds` / `alerts`）能正常执行，但 `help` 里**没有这一行**；
  别名只存在于分派逻辑里、`help` 完全不提；`redo` 也没有独立说明。
- **原因**：命令清单在四处各维护一份（分派 `switch`、`help` 输出、Tab 补全词、别名表），必然漂移。
- **现在**：`help` 补上 `config` 行与 `redo` 独立说明，并新增**自动生成的「命令别名」对照块** ——
  34 个名字（16 主名 + 18 别名）在 `help` 里全部查得到。

### 2. 别名 `u` 会把「重做」清空

- **现象**：`add …` 之后用 `u` 撤销，再想 `redo` 已经无效；而用 `undo` 却正常 —— 同一个动作两个别名行为不同。
- **原因**：`u` 当时被当成"新改动"又压了一次撤销栈，顺手清空了 redo。
- **现在**：`u` 与 `undo` 行为**完全一致**。

### 3. Tab 补全在几个位置上补错

- **现象**：① `update 1 60 餐` 按 Tab **补不出来**，而 `update 1 餐`（金额位）反而蹦出"餐饮"；
  ② `add ` 在**金额位**就提示类别；③ `@日期` 是位置无关参数（`add @2027-08-18 300 购物` 与
  `add 300 购物 @2027-08-18` 都合法），写在中/后段时会把后面的槽位整体顶偏；
  ④ `del` / `pay` / `add` 在多余槽位重复提示 id / 类别。
- **原因**：补全按"第几个 token"当槽位，而 `@日期` 不占槽位、金额位又不该提示类别。
- **现在**：改为**语义槽位**（命令名与 `@日期` 都不计入），每个槽位给对的候选。真实浏览器按键实测：

  | 输入 + Tab | 结果 |
  | --- | --- |
  | `update 1 60 餐` | → `update 1 60 餐饮` |
  | `update 1 餐` | → **不动**（金额位不再提示类别） |
  | `add 50 餐` | → `add 50 餐饮` |
  | `a 50 交` | → `a 50 交通`（别名同样生效） |
  | `add @2027-08-18 50 餐` | → `add @2027-08-18 50 餐饮` |
  | `list @t` | → `list @today` |

### 4. 表格列宽不一致 / 窄窗口被挤断

- **现象**：summary、forecast、assets、config 四套输出各自写死列宽（`padEnd(22)` / `padEnd(24)` / 手写空格），
  数字列互相对不齐；窄窗口下长标签会被挤到下一行。
- **现在**：四类输出统一走同一个渲染器，列宽**按窗口自适应**（≈终端字符列数 × 26%，夹在 14~24，`resize` 时重算）。
  实测 1400 / 900 / 520 三种宽度：列宽 **24 / 24 / 16**、状态栏与工具栏正常折行、**均无横向滚动**。

## 二、内部重构（不改行为，但决定后续可维护性）

| 收敛掉的重复 | 以前 | 现在 |
| --- | --- | --- |
| **颜色** | CSS 定义 12 个主题令牌，JS 侧另有 **224 处** `c:"#3dff7a"` 之类内联字面量，同一语义色在两层各写一遍（换配色要全文件替换，极易漏改 —— v0.0.3 那个"弹窗黑字看不见"正是漏改的产物） | 新增 `COLOR` 表：启动时**从 `:root` 的 CSS 变量读取真实值**（读不到则回落内置字面量）。JS 里引号 hex 从 **316 处降到 15 处**（只余 `COLOR` 的 13 个默认值 + 调色板 2 个扩展色），**299 处引用走 `COLOR.*`** → 改配色只需改 `:root` 一处 |
| **表格渲染** | `printSummaryReport` / `doForecast` / `doAssets` / `showSettings` **4 套实现**（其中两份逐字节相同），另有 3 个从未被调用的表格助手 | 统一 `kvRow(key, value, width, color, glow)`，列宽自适应 |
| **命令清单** | 分派 `switch`、`help`、补全词、别名表 **各一份** | 唯一登记表 `COMMANDS`，由它派生 help 输出、别名解析、补全词 |

- **删除死代码**：`boxLines()`、`hr()`、`tableRow()`、`periodSpend()`、`catNameOfRecord()`、
  `recordMoneyInv()`、`recordHistory()`、常量 `INVEST_SHARE`、`printSummaryReport()` 从未被读取的 `budgetRef` 形参、
  `buildReportText()` 里的恒等三元。
- **删除死 CSS**：`.line0`~`.line5`、`.lvl-0`~`.lvl-4`、`table.kv`、`.tag`、`.bar-track`、`.bar-fill`、`.error`
  （页面上从未出现过这些类名）。
- **响应式契约原样保留**（本次专门回归验证，未做任何削弱）：
  `header` / 工具栏 / 理财条 `flex-wrap:wrap`、弹窗 `width:min(560px,94vw)` + `max-height:90vh`、
  终端 `overflow-y:auto` 且长行 `white-space:pre-wrap`、输入区 `overflow:hidden` + `min-width:0`。

## 三、回归装置入仓（本版本附带）

原本放在系统临时目录（随时可能被清理、且写死了本机绝对路径）的测试装置，本版本**移入仓库 `tests/`**：

```powershell
node tests/run-all.mjs     # 单一入口：跑完 5 个套件 + 基线校验，合计 353 条断言
```

- 自建 DOM stub 直接执行 `index.html` 的内联脚本，无需浏览器；**时钟冻结**（默认 `2027-08-30`），
  避免"换一天跑就全红"的假故障。
- 任一套件失败、或**断言数与基线不符**（护栏被悄悄删掉或改期望值）都会以非 0 退出。
- 默认夹具是全**合成**账本（日期/金额/备注均为编造值，不含任何真实账目）；
  想拿自己的备份做冒烟测试可设 `BT_FIXTURE` 指向本地备份（只读，不会写回仓库）。
- 详见 [`tests/README.md`](https://github.com/goddog114514/budget-terminal/blob/v0.0.5/tests/README.md)。
