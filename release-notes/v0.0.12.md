## 一、做了什么

| 能力 | 说明 |
| --- | --- |
| 自动填充地址 | 每笔 `add` 成功后异步定位 → 腾讯地图逆地理编码 → 只取 `省/市/区` 写进该条记录（如 `广东省深圳市南山区`）；直辖市同名去重 |
| 全手动 | 主页「地点 ▾」可切成「全手动（不填则空）」，完全不调用定位；地点留空 |
| 手填 / 补填 / 清除 | `#地点` 参数、`place <id> <地点>`（别名 `where`）、`place <id> -` 清除、`update … #-`；「记一笔」双选项卡与 `✎ 编辑` 弹窗都有地点输入框 |
| 按地点浏览 | 列表行显示 Canvas 准星 + 地名（与左上角定位图标共用 `paintGeoIcon`）、`export md|txt` 的逐笔记录用 `地点: 地名` 文字标签；`config` 显示当前模式与打码 Key |
| 仅 `add` 自动 | `amort` 分摊成本**从不自动定位**，需要就在弹窗里手填 |

## 二、本地双击运行：需要自己的腾讯地图 Key

应用是零依赖单文件，本地 `file://` 打开时没有服务端代管 Key，所以**自动模式需要自备 Key**，代码里不预置任何有效 Key。

1. [腾讯位置服务控制台](https://lbs.qq.com/dev/console/home) → 注册登录。
2. 「应用管理 → 我的应用 → 创建应用」→「添加 Key」。
3. 启用 **Web端（JSAPI GL）** 并勾选 **WebServiceAPI**（`TMap.service.Geocoder` 依赖）。
4. 在「地点 ▾ → 地点设置」填入，或执行 `config set geokey <你的Key>`；`config set geokey off` 清空。

代码里只有一条显式占位符模板：

```
https://map.qq.com/api/gljs?v=1.exp&libraries=service&key="请在腾讯位置服务开放平台申请自己的key并替换此占位符"
```

运行时 SDK 地址由 `config set geokey` 写入的值拼接，占位符不会被发出；`echoCommand()` 与 `config` 页面都对 Key 打码。
`file://` 下 Referer 为空，控制台的**域名白名单请留空 / 不启用**；商业用途必须改后端代理鉴权。

## 三、架构与合规

- **数据**：`place` 在 `makeRecord` / `normalizeRecords` / `doUpdate` / `renderRecordRow` / `buildReportText` 五处对称保留；旧备份缺字段回落 `""`。`LS_KEY`、`app:"budget_term"`、`version:2` 不变。
- **H4 统一提交点**：异步结果回来时 `applyAutoPlace()` 直接调 `commit()` 落盘 + `refreshAll()`，**不经 `mutate`** → 一次记账仍只压一步撤销；记录已删/已撤销/用户已手填则丢弃结果。
- **H5 双通道对称**：主页下拉、设置弹窗、记一笔弹窗、编辑弹窗全部拼命令回灌 `runCommand`，与命令行同一条路径；`refreshGeoUI()` 并入 `refreshAll()`。
- **合规**：只接腾讯地图 JSAPI GL（`TMap.service.Geocoder`），不手写 `fetch` 调 WebService，不接任何境外/无资质地图源；SDK 按需加载、URL 只带用户自填 Key。
- **隐私**：`navigator.geolocation` 的 WGS-84 坐标在本地换算 GCJ-02 后仅用于这一次逆地理编码，**不写进记录 / 备份 / 导出**；落盘只有行政区字符串。外部地名先清洗控制字符、截断 60 字，只用 `textContent` 渲染（`innerHTML` 仍恰好 4 处且都是清空）。
- **降级**：无定位能力（含离线测试环境）、拒绝授权、超时、无网、无 Key、SDK 失败、空地址 → 静默跳过，绝不阻断记账；有定位能力但没配 Key 时只提示一次。

## 八、同版迭代 · 启动预热 + 左上角 Canvas 定位（2026-11-09 追加，用户反馈）

> 第七节的 871 / 51 是上一轮时点；**当前权威基线为 896 / 55**。本节覆盖第一、三节中关于「异步回填」的描述。

- **现象**：自动定位晚于数据落盘 —— 记账数据已写入后定位结果才回来，只能事后回填。
- **重构**：定位从「每笔 `add` 之后」整体前移到「打开页面时一次」。`boot()` 调 `primeGeoLocation()`；结果只更新内存 `geoCache`、独立缓存 `budget_term_geo_v1`、左上角 badge，**异步链路不再触碰 `state.records`、不再调 `commit()`**。`doAdd` 同步 `rec.place = currentGeoPlace()`，随命令 `mutate → commitIfDirty()` 一次落盘。`applyAutoPlace()` / `startAutoPlace()` 整体删除。
- **触发次数**：打开一次 = 一次；切模式 / 填 Key / 点左上角图标各补一次；**记账时零定位请求**。`geoPrimed` 守卫防止重复申请。
- **左上角**：Canvas 2D 手绘准星（16×16 @2x，圆环 + 四向直角刻线 + 方形中心点），状态色取 `COLOR.*`（青/绿/黄/灰）；文字只显示区名如 `南山区`。**不用 Emoji、不用外部图片**；`getContext` 不可用静默降级。`renderGeoBadge()` 由 `refreshHeader()` 清空后第一个 append，不占 `#statusbar .stat` 索引。
- **兜底**：预热未完成时首笔地点留空且**不事后回填**；上次会话地名缓存让下次打开首笔即可同步带上；结果回来复查 `geoMode` / `geoKey`，期间切全手动或清 Key 只丢弃缓存更新。
- **根因消除**：原 P0「对象引用校验 / 地点独立一步撤销 / 迟到结果丢弃」所防缺陷不再可能发生；`undo` 撤整笔、`redo` 一并恢复地名。
- **护栏**：`test8.mjs` 95 → **120 条**；`app.mjs` 支持 `seedStorage` 注入 Key 让 boot 预热真实跑起来；`mutate-amort.mjs` 51 → **55 组**（13 组地点护栏重写、4 组漂移锚点修复）。全量 **896 PASS / 0 FAIL**，**55 组变异全部被抓住**。
- **Key**：自备 Key 只在运行时通过 `config set geokey` / 设置弹窗填入并存本机 localStorage；**代码与仓库不含任何有效 Key**，终端与 `config` 页均打码。
- **仍未做**：真实浏览器视觉验证（本机 Edge 无头零输出）、git 提交 / 推送 / 打标签。
