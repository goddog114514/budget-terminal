## 一句话

以前 `amort 3000 365 房租`（8 月 30 日记）之后，**只有 8 月 30 日那天显示 `¥8.22`**：
8 月 31 日右上角「今日预算」是 `¥0.00`，8 月整月周期消费只有 `¥8.22`，
`list @2027-08-31` 返回"暂无匹配记录"，`summary`/`export` 也都只算一天。
现在这笔钱在**生效窗口内的每一天**都计入消费 —— 8 月 = 2 天（`¥16.44`）、9 月 = 30 天（`¥246.60`），
列表、总结、导出、每日圆点全部一致；**投资仍是按总价一次记入**，一分不少。

## 一、缺陷现象（v0.0.6）

以 `amort 3000 365 房租 年付 @2027-08-30` 为例（消费占比 85%）：

| 看的地方 | v0.0.6 显示 | 应该是 |
| --- | --- | --- |
| 8/30 的「今日预算」 | `¥8.22` | `¥8.22` ✅ |
| 8/31 的「今日预算」 | **`¥0.00`** | `¥8.22` |
| 8 月周期消费 | **`¥8.22`** | `¥16.44`（8/30、8/31 两天） |
| `list @2027-08-31` | **"暂无匹配记录"** | 列出这笔（它 8/31 确实在摊） |
| `list @2027-09` | **列不到** | 列出这笔 |
| `summary` / `summary month` | **`¥8.22`** | 按落在窗口内的天数 |
| `summary month` 的日均 | **`¥0.27`** | `¥0.55` |
| 累计可用余额 | 只扣一天 | 扣"到今天为止"已发生的天数 |

## 二、原因

`amort` 记录里的 `amount` 存的是**每天**金额，但所有统计都写成
`records.filter(r => r.date 在区间内).reduce((s,r) => s + r.amount, 0)` ——
**"记一天"被当成了这条记录的全部生命周期**。v0.0.6 只把"消费口径"做成了每天金额，
却没做"统计窗口内的天数"，于是那笔钱除记账当天外全部消失。

同一个错误在**五处**各写了一遍：`periodSnapshot()`、`todaySnapshot()`、`totalCharge()`、
`collectWindow()`、`doList()`。

## 三、解决：窗口统计的唯一入口

不再让任何地方自己按日期求和，改为共用一组新函数（**派生值一律现算**，不建缓存）：

| 函数 | 作用 |
| --- | --- |
| `recWindow(r)` | 生效窗口 = 记账日起连续 `recDays(r)` 天（普通消费即 `date~date`，旧记录零特判） |
| `recDaysInRange(r,start,end)` | 窗口与统计区间的**交集天数** |
| `recInWindow(r,start,end)` | **行筛选**统一口径（有交集就算，不再只认 `r.date`） |
| `recAmountInRange(r,start,end)` | 该记录在区间内的消费额 = `交集天数 × 每天金额` |
| `recAmountUpToToday(r)` | 只累计到今天（`totalCharge` 用，未来天数不提前占用） |
| `sumRange(rows,start,end)` / `collectWindow(start,end,cat)` | 合计与"其中分摊"小计；`periodSnapshot` 也改为复用 |

### 修好之后的行为

- **每日预算**：生效窗口内每一天都计入当天消费（不再只有记账当天）。
- **周期预算**：按"落在本期内的天数"计 —— 8 月记的年付房租，8 月算 2 天、9 月算 30 天、整年覆盖时算 365 天。
- **消费列表**：日期/月份/周期筛选都按**窗口有交集**命中；`list @2027-08-29`（生效前一天）依然列不到。
  合计按落在筛选窗口内的天数计，并多一行「其中分摊成本 ¥X」。
- **总结 / 导出**：`summary`（day/week/month/cat）与 `export` 全部同口径，并新增「其中分摊成本」行。
- **累计可用余额（含结转）**：只累计到**今天**为止已发生的天数 —— 记一笔年付房租不会让余额立刻变负，
  未来的天数等日历走到才逐日计入。
- **投资侧不变**：仍按**总价一次记入**，恒等式 `Σ(每天 ÷ 消费占比) = 总价 ÷ 消费占比` 照旧成立。

### 展示面

```text
#1  2027-08-30  房租  ¥    8.22  [分摊365天: 总3000.00 → 每天8.22  2027-08-30~2028-08-28]  ...
```

列表行标出**生效区间**，导出报告的逐笔行同样标注起止日期。

## 四、兼容性（**不需要迁移**）

- **未改动**：`LS_KEY`、备份 `app`/`version` 头、字段名与 `amount` 语义、`amortDays`/`amortTotal`、
  `r2`/`r6` 精度、`INV_EPS`/`INV_UNIT`、13:2 拆池、响应式契约、`COMMANDS` 命令清单（本版**不新增命令**）。
- 老备份（含 v0.0.1 起）导入结果与升级前**逐字段一致**；本版改的只是"统计窗口"的算法，
  没有重算或改写任何已存记录的字段。
