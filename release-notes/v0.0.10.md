# BUDGET::TERM v0.0.10 发布说明

> 单文件本地记账终端（双击 `index.html` 即用）· 本轮是**功能版**：
> 新增 `chart` 图表总结，把**每日 / 周 / 周期 / 自然月**的预算情况自动画成
> **柱状图、饼图（可二选一或两者都画）**，并输出**自动分析与结论建议**。
> **数据结构、存储格式、备份头、既有命令语义一个字都没改** —— 老数据 / 老备份零迁移。

- **发布日期**：2026-11-04
- **交付方式**：合入主仓库 `budget-terminal/` 并**推送 GitHub**（附注标签 `v0.0.10`）；`HANDOVER.md` 仍按约定只留本地、不入库
- **升级方式**：用新的 `index.html` 覆盖旧文件即可；v0.0.1 起的备份都能正确导入，**无需迁移**
- **版本号**：`config` 输出显示 `v0.0.10`
- **回归**：**693 条**无头断言全绿（138 / 55 / 85 / 90 / 92 / 43 / 190），**27 组**脚本变异测试全部被护栏抓住（图表 4 组 + 合并入口 4 组为本版新增）

## 一句话

以前只能看数字（`summary` 的类别迷你条），现在可以直接看图：
一个 `chart` 命令覆盖四种窗口、两种图型，并把"超没超预算、钱花在哪、趋势往哪走、下一步该怎么调"写成文字结论。

---

## 一、新增能力

### 1. 四种窗口，与 `summary` 同源

| 写法 | 窗口 |
| --- | --- |
| `chart day` | 今日（单日没有时间维度，柱状图按类别分桶） |
| `chart week` | 本周（周起始日跟随 `set weekstart`） |
| `chart period` / `chart` | 当前记账周期（自然月 / 自定义起始日 / 滚动 N 天都跟随现有设置） |
| `chart month` / `chart month 2027-07` | 自然月，可指定月份 |

- 窗口解析抽成 `resolveWindow(kind, ref, cat)`，`doSummary()` 与 `doChart()` 共用同一份边界定义；
  消费额一律由 `collectWindow()` 给出。
- 柱状图的**每个桶**也单独走 `collectWindow(桶起, 桶止, 类别)`。
  所以一笔 `amort` 分摊成本会按"落在桶内的天数"计入，不会只在记账那天出现一次（v0.0.7 修的 F13 不在图表里复发）。
- 长窗口自动合并（最多 `CHART_MAX_BUCKETS = 12` 柱），窄屏也放得下；首尾严格闭合。

### 2. 图型可任选

- `bar` 柱状图 / `pie` 饼图 / `both`（默认，两者都画）；窗口、图型、类别的顺序自由，如 `chart pie week 餐饮`。
- 柱状图：柱高 = 该桶消费，超过额度会按既有 `barLevel()` 变色；黄色虚线 = **本期日均发放 × 消费占比**折算的日均预算参考线。
- 饼图：`conic-gradient` 绘制的**类别金额占比**（不是按笔数），配色走 `catColor()`，旁边图例给金额与百分比；空窗口画灰环并提示"没有消费记录"。
- **图形 + 文本双份**：DOM 图形下方始终另有一份纯文本「数据明细」表（`kvRow()` 渲染），数字可复制、可阅读；用户数据一律 `textContent`。

### 3. 自动分析与总结

输出「自动分析」表格：窗口总消费、日均、占用、参考发放额度、预算使用率、峰值时段、超参考额度桶数、零消费桶数、
Top1 类别、Top3 集中度、分摊成本占比、前后半段趋势；
再给一句**结论**和按数据生成的**建议**（超预算削减、类别过度集中、异常大额、固定支出占比高、未完全投资等）。

> 口径写死在输出里：**柱高 / 饼图 = 消费口径**；**预算使用率 = 预算口径**（消费 ÷ N = 占用，N 默认 85%），两者差一个 N。

### 4. 双通道与命令规范

- 工具栏新增「图表总结 ▾」下拉，6 个选项都是完整命令字符串（`chart day both` … `chart period pie`），
  和命令行敲同一条命令完全等价；按钮同样回灌 `runCommand()`，日志与撤销栈一致。
- `COMMANDS` 登记主名 `chart` + 别名 `charts` / `viz` + 一条子用法；`dispatch` / `help` / Tab 补全 / README / 架构 §1.4 全部由登记表派生。
- 参数写错（两个窗口、非法 `@日期`、多个类别）给**用法提示并中止**，不静默忽略。

## 五、已知边界（明确标注）

- 饼图对**未登记类别**沿用 `catColor()` 的兜底色，多个自定义类别可能同色（与现有 `list` / `summary` 的类别配色行为一致，未另造一套调色板）；
- 预算参考线按**当前周期**的日均发放折算；查看历史月份时它表示"按当前预算水平应花多少"，不是那个月当时的实际预算（当期预算覆盖不回溯历史）；
- `chart` / `report` 的输出是终端内的图 + 文本，**不改变 `export md|txt` 的报告内容**；需要留档请从终端复制文本明细。

## 六、同版迭代：四个按钮合并成一个（版本号仍为 `v0.0.10`）

按仓库主人要求，把工具栏的「周期总结 / 日总结 / 周总结 / 图表总结」四个入口**合并成一个「总结与图表 ▾」**，版本号保持不变。

- **先选范围，再输出**：下拉与「消费列表 ▾」共用同一套 `data-range` + `toggleDd()` / `closeDd()` / `onRangeMenuItem(kind, target)` / `RANGE_COMMANDS`；
  选「手动输日期…」复用**同一个** `#dateModal`，`dateModalTarget` 决定提交时拼 `list` 还是 `report`，弹窗标题同步切换，日期归一化 / 校验 / 实时预览逻辑完全不重复。
- **一次同时输出图表和柱状图**：新增 `report`（别名 `overview`），固定 `both`，一次打印 `printSummaryReport()` 的完整总结表（进度条 / 类别迷你条 / 未投清单 / 日均）+ 柱状图 + 饼图 + 数据明细 + 自动分析 + 结论建议。
  绘图部分抽成 `renderChartBody()`，`chart` 与 `report` 共用，没有第二份实现。
- **指定日期不再被当成整月**：`resolveWindow()` 新增 `kind="date"`；手动填 `YYYY-MM-DD` 时按那一天统计（单日按类别分桶），填 `YYYY-MM` 时按自然月。
- **清理**：四个旧按钮、`chartDd` 与 `toggleChartDd` / `closeChartDd` / `onListMenuItem` 等第二套下拉实现全部删除，不留死代码；`report` 是纯只读命令，不写盘、不进撤销栈。
- **护栏**：`test7.mjs` 扩到 190 条（新增合并入口 / 范围映射 / 日期弹窗 target / 双通道等价 / 指定日期窗口），变异脚本扩到 27 组（新增 4 组 `m_report_*`），全部被抓住。
